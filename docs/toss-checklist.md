## 4. 심사 기준에 맞춰 이미 반영한 것

- 외부 사이트로 화면 이동 금지 → 커뮤니티 원문·유튜브 링크는 토스 안에서 SDK(`Device.openURL`)로 기기 브라우저에 열어요.
- iframe 금지 (유튜브만 예외) → 유튜브 공식 플레이어만 써요.
- 라이트 모드만 → 토스 안에서는 다크 토글을 숨기고 화이트로 고정해요.
- 핀치 줌 끄기 → `index.html` viewport 설정.
- 안드로이드 뒤로가기 → 플레이어·시트가 열려 있으면 닫고, 첫 화면이면 미니앱이 종료돼요.
- 진입 시 자동 바텀시트 없음, 로그인·결제·광고 없음.
- 서버 통신은 HTTPS(GitHub Pages)만.

## 5. 심사에서 물어볼 수 있는 것 (답변 준비)

- **커뮤니티 원문 링크가 "외부 링크"인데 괜찮나요?** → 정책상 허용되는 "단순 정보 조회" 성격이고, 핵심 기능(인기글 목록 보기, 영상 재생)은 앱 안에서 끝나요. 반려되면 커뮤니티 카드를 상세 시트(제목·수치·요약)로 되돌리는 안을 준비해 두었어요.
- **타인의 콘텐츠를 보여주나요?** → 제목·링크·공개 수치만 보여주고 본문은 저장하지 않아요. 유튜브는 공식 API와 공식 플레이어만 써요.
- **AI를 쓰나요?** → 영상 한 줄 소개에만 선택적으로 써요. 쓰는 경우 화면에 "AI 요약" 표시가 필요해요(현재 ANTHROPIC_API_KEY 미설정 → 유튜브 설명 첫 줄 사용, 표시 불필요).
